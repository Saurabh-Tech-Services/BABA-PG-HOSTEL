# BABA PG & HOSTEL — LLM Context

## Project
Website for **BABA PG & HOSTEL**, a boys PG and hostel in Jaat Colony, Dankaur, Greater Noida, UP.

## Stack
- TanStack Start (React SSR) + TanStack Router (file-based)
- Tailwind CSS v4, Radix UI / shadcn components
- EmailJS for booking form, Vite 8, deployed on Vercel

## Key Files
- `src/data/hostel.ts` — single source of truth for all business data
- `src/data/gallery.ts` — gallery images list
- `src/lib/seo.ts` — SEO helpers, OG images, structured data
- `src/routes/` — file-based pages (index, rooms, pricing, facilities, gallery, about, contact, book-now)
- `src/components/site/` — reusable page sections
- `public/sitemap.xml`, `public/robots.txt` — SEO files
- `vercel.json` — Vercel deployment config
