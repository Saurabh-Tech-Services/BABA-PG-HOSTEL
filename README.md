# BABA PG & HOSTEL — Website

Premium, SEO-optimized boys PG & hostel website for **BABA PG & HOSTEL**, Jaat Colony, Dankaur, Greater Noida.

🌐 **Live site**: [shivibabapg.com](https://shivibabapg.com)

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) (React + SSR)
- **Router**: TanStack Router (file-based)
- **Styling**: Tailwind CSS v4
- **UI**: Radix UI + shadcn/ui components
- **Email**: EmailJS (booking / contact forms)
- **Build tool**: Vite 8
- **Deployment**: Vercel

## Local Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
```

Open **http://localhost:5173**
